  • ImplementationConfig — Input file(s) configuration.

source class ImplementationConfig(sub_configdic: dict = None)

Bases : BaseConfigSection

Input file(s) configuration.

Attributes

  • mode : str — Defines the operating mode for isofit. Current options are: inversion, inversion_mcmc, and 'simulation'.

  • inversion : InversionConfig — optional config for running in inversion mode.

  • n_cores : int — number of cores to use.

  • task_inflation_factor : int — Submit task_inflation_factor*n_cores number of tasks.

  • ip_head : str — Ray - parameter. IP-head (for multi-node runs).

  • redis_password : str — Ray - parameter. Redis-password (for multi-node runs).

  • ray_include_dashboard : str — Ray - parameter. Boolean to include dashboard.

  • ray_temp_dir : str — Overrides the standard ray temporary directory. Useful for multiuser systems.

  • ray_ignore_reinit_error : bool — Boolean to tell ray to ignore re-initilaization. Can be convenient for multiple Isofit instances.

  • io_buffer_size : bool — Integer indicating how large (how many spectra) of chunks to read/process/write. A buffer size of 1 means pixels are processed independently. Large buffers can help prevent IO choke points, especially if the

  • max_hash_table_size : int — The maximum size of inversion hash tables. Can provide speedups with redundant surfaces, but comes with increased memory costs.

  • debug_mode : bool — A flag to run the code in debug mode, which circumvents ray.

  • isofit_version : str — ISOFIT version used.
