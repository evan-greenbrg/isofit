source class RadiativeTransferEngineConfig(sub_configdic: dict = None, name: str = None)

Bases : BaseConfigSection

Radiative transfer unknowns configuration.

Attributes

  • name : str — Name of config - optional, and not currently used.

  • engine_name : str — Name of radiative transfer engine to use - options ['modtran', '6s', 'sRTMnet', 'LibRadTran'].

  • engine_base_dir : str — base directory of the given radiative transfer engine on user's OS.

  • engine_lut_file : str — File containing the prebuilt LUT file (hdf5).

  • wavelength_file : str — Optional path to wavelength file for high-res atmospheric calculations

  • wavelength_range : List — The wavelength range to execute this radiative transfer engine over.

  • environment : str — Additional environment directives for the shell script.

  • lut_path : str — The path to the look up table directory used by the radiative transfer engine.

  • sim_path : str — Path to the simulation outputs for the radiative transfer engine.

  • template_file : str — A template file to be used as the base-configuration for the given radiative transfer engine.

  • treat_as_emissive : bool — Run the simulation in emission mode

  • glint_model — Flag to indicate whether to use the sun and sky glint model from Gege (2012, 2014) in the forward model. Only currently functional with multipart MODTRAN.

  • rt_mode : str — Radiative transfer mode of LUT simulations. 'transm' for transmittances, 'rdn' for reflected radiance.

  • statevector_names : List — Names of the statevector elements to use with this radiative transfer engine. Must be a subset of the keys in radiative_transfer->statevector. If not specified, uses all keys from radiative_transfer->statevector. Auto-sorted (alphabetically) below.

  • lut_compression : str — Compression method to use for the LUT NetCDF

  • lut_complevel : int — The compression level to use for the chosen method

  • aerosol_template_file : str — Aerosol template file, currently only implemented for MODTRAN.

  • aerosol_model_file : str — Aerosol model file, currently only implemented for MODTRAN.

  • multipart_transmittance : str — Use True to specify triple-run diffuse & direct transmittance estimation. Only implemented for MODTRAN.

  • emulator_file : str — Path to emulator model file

  • emulator_aux_file : str — path to emulator auxiliary data - expected npz format

  • predict_parallel_chunks : int — If emulator predictions are in parallel. How many chunks to run. Keep to a small number for systems with little memory and slow read.

  • day : int — 6s-only day parameter.

  • month : int — 6s-only month parameter.

  • elev : float — 6s-only elevation parameter.

  • alt : float — 6s-only altitude parameter.

  • obs_file : str — 6s-only observation file.

  • solzen : float — 6s-only solar zenith.

  • solaz : float — 6s-only solar azimuth.

  • viewzen : float — 6s-only view zenith.

  • viewaz : float — 6s-only view azimuth.

  • earth_sun_distance_file : str — 6s-only earth-to-sun distance file.

  • irradiance_file : str — 6s-only irradiance file.

  • rte_configure_and_exit : bool — Indicates that code should terminate as soon as all radiative transfer engine configuration files are written (without running them)

  • emulator_batch_size : int — Batch size for sRTMnet predictions. Set smaller to reduce memory usage, larger for faster emulation.

source class RadiativeTransferConfig(sub_configdic: dict = None)

Bases : BaseConfigSection

Forward model configuration.

Attributes

  • interpolator_style : str — Style of interpolation. - mlg = Multilinear Grid - rg = RegularGrid Speed performance: mlg >> stacked rg >> unstacked rg Caching provides significant gains for rg, marginal for mlg

  • overwrite_interpolator : bool — Overwrite any existing interpolator pickles

  • cache_size : int — Size of the cache to store interpolation lookups. Defaults to 16 which provides the most significant gains. Setting higher may provide marginal gains.

  • terrain_style — Style of terrain to use in the forward model - options are 'flat', 'dem', 'solved'

  • min_cos_i : float — Minimum cos(i) value used in LUT component calculations. Only relevant if terrain_style is 'dem' and a 6 component model is used. This can avoid runaway results at low values where diffuse radiance dominates.
