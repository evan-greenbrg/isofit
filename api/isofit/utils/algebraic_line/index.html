Run pixel-wise algebraic inversions, using provided atmosphere file. If no atmosphere file is provided, it will be created via interpolation from the state solution.

  • rdn_file : str — Path to the radiance file

  • loc_file : str — Path to the location file

  • obs_file : str — Path to the observation file

  • isofit_dir : str — Path to the isofit directory

  • isofit_config : str — Path to the isofit configuration file

  • segmentation_file : str — Path to the segmentation file (optional)

  • num_neighbors : list — Number of atmospheric neighbors to use for interpolation

  • atm_sigma : list — Smoothing sigma for the atmospheric interpolation

  • n_cores : int — Number of cores to use for parallel processing

  • num_iter : int — Number of iterations for the inversion

  • output_rfl_file : str — Path to the output reflectance file

  • atm_file : str — Path to the atmosphere file

  • logging_level : str — Logging level (default: INFO)

  • log_file : str — Path to the log file (default: None)
