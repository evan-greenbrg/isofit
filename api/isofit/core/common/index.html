source class VectorInterpolator(grid_input: List[List[float]], data_input: np.array, version='mlg')

Linear look up table interpolator. Support linear interpolation through radial space by expanding the look up tables with sin and cos dimensions.

Parameters

  • grid_input : List[List[float]] — list of lists of floats, indicating the gridpoint elements in each grid dimension

  • data_input : np.array — n dimensional array of radiative transfer engine outputs (each dimension size corresponds to the given grid_input list length, with the last dimensions equal to the number of sensor channels)

  • version — version to use: 'rg' for scipy RegularGridInterpolator, 'mlg' for multilinear grid interpolator

source calculate_resample_matrix(wl: np.array, wl2: np.array, fwhm2: np.array, srf_file: str = None) → np.array

Calculate the resampling matrix for a given set of wavelengths and FWHM. Once calculated, resmpling is just the dot product of this matrix with the vector to be resampled.

Parameters

  • wl : np.array — sample starting wavelengths

  • wl2 : np.array — wavelengths to resample to

  • fwhm2 : np.array — full-width-half-max at resample resolution

  • srf_file : str — SRF for the sensor if not assuming Gaussian

Returns

  • np.array — transformation matrix (H)

total: int, iterable Total items in iterable. source compare(a, b, threshold=0.8, not_same=True)

Compares strings in a to strings in b

Parameters

  • a : str | list[str] — A string or list of strings to compare with b

  • a : str | list[str] — A string or list of strings to compare with a

  • threshold : float, default=0.8 — Ratio threshold to meet to be considered matching. Must be between 0 and 1.

  • not_same : bool, default=True — Only include matches in which the two strings are not the same

Returns

  • matching : dict — For each string in a, return a list of strings in b that meet the matching threshold
